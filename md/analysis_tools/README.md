# Frozen di-NMe analysis source

di_nme_roe_analysis_tools_v1.tar.gz contains the original conformational,
sampling-core and ROE implementations together. Its original archive hash is
unchanged. Earlier overlapping M1–M3/sampling packages and the static server
collector were removed. The archive retains its original source identities,
asset pins and lab-coordinate dependencies. Portable shared implementations
remain in ../code/.
